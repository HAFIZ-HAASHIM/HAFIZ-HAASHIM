# Security Policy

## Supported Versions

Security updates and patches are actively applied to current project releases.

| Project / Version | Supported          |
| ----------------- | ------------------ |
| Latest Main       | :white_check_mark: |
| < Latest Release  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within any of my repositories or projects:

1. Please do not disclose vulnerabilities publicly via open issues.
2. Report the vulnerability privately via email: [haashimmuhammad7@gmail.com](mailto:haashimmuhammad7@gmail.com).
3. Include clear steps to reproduce, impact assessment, and potential mitigations.

All legitimate security reports will be investigated and addressed promptly.

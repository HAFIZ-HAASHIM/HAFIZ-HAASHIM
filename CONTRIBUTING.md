# Contributing Guidelines

Thank you for your interest in contributing to Haashim's projects and repositories!

## How to Contribute

1. **Reporting Issues:**
   - Use GitHub Issues to submit bug reports, feature suggestions, or documentation enhancements.
   - Provide detailed steps to reproduce any issue.

2. **Submitting Pull Requests:**
   - Fork or branch from `main`.
   - Create a feature branch: `git checkout -b feature/your-feature-name`.
   - Keep commits modular, descriptive, and clean.
   - Open a pull request against `main` with a clear description of the modifications.

3. **Code Quality Standards:**
   - Adhere to clean architecture, modern coding conventions, and proper documentation.
   - Ensure all assets, models, and scripts pass static validation and tests.

4. **Community Collaboration:**
   - Be respectful, constructive, and collaborative in discussions, reviews, and issue threads.
